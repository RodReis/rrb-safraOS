# Especificações por fatia

Uma SPEC descreve uma fatia e usa número reservado no `STATUS.md`: problema/resultado; dentro/fora; regras/cenários; contratos/dados; falhas/recuperação; observabilidade; critérios verificáveis; plano de prova; decisões/dúvidas resolvidas pelo PI. Passos ficam em `plans/`; estrutura em ADR.
