# MVPs e fatias

Cada `MVP-NNN.md` recorta o produto em fatias verticais. Estrutura: resultado de negócio; dentro/fora; dependências/riscos; checklist de Slices; gate; métricas. Passo técnico não vira fatia. Reservar `SPEC/F` no `docs/STATUS.md` antes de numerar.

Todo MVP referencia sua seção em `docs/FORA-DE-ESCOPO.md`. Esse registro explica recortes, mas não substitui backlog, SPEC ou status remoto.
